      Stasjonsformat

      Samme JSON-struktur som i gnome-radio-oop. Rediger direkte, eller importer ei fil. Endringer lever i minnet — eksporter for å ta dem med videre.

      Om denne utgaven

      Dette er Norge - Radio bygd som én HTML5-fil: samme oppdeling i objekter som Python/GTK4-utgaven, men med nettleserens egne API-er i stedet for GStreamer, libshumate og D-Bus.

      Klasser

      • Station — én kanal, med frekvens, posisjon og farge
      • StationStore — CRUD, favoritter, import og eksport
      • RadioPlayer — avspilling og tilstandsmaskin over <audio>
      • MediaSessionAdapter — MPRIS2-erstatning via Media Session API
      • DialView, StationListView, MapView, DataView
      • Application — kobler lager, spiller og visninger sammen

      Slik svarer det til GTK-utgaven

      • GStreamer playbin → HTMLAudioElement
      • MPRIS2 over D-Bus → navigator.mediaSession med spill, pause og kanalbytte
      • libshumate-kart → tegnet SVG-kart med de samme Tango-fargene
      • JSON-stasjonsfil → samme skjema, lest og skrevet i Data-fanen

      Det nettleseren ikke får til

      • ICY-metadata om låt og artist krever CORS-tilgang på strømmen; panelet viser derfor kanalinfo og avspillingstilstand.
      • FPGA-brua mot ICENode hører hjemme på maskina, ikke i nettleseren.
      • Ingen lagring på disk: eksporter JSON for å beholde endringene.

      Tastatur

      • ← → på skalaen: finstill 0,1 MHz
      • ↑ ↓: hopp til neste eller forrige stasjon
      • Mellomrom på skalaen: spill eller pause
